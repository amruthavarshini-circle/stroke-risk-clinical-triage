1. Title slide: project title, student name/roll number, mentor.
2. Problem statement and analytical questions.
3. Dataset overview, data dictionary and cleaning.
4. EDA: target balance and key distributions.
5. EDA/statistics: hypertension and glucose findings with test results.
6. Feature engineering and preprocessing.
7. Modeling approach and rationale (Logistic Regression plus comparison model).
8. Model comparison and metrics.
9. Confusion matrix, error analysis and Streamlit screenshots/live demo.
10. Key insights, limitations and future scope.

Use actual plots and measured metrics from your completed project. Do not fabricate performance values.
