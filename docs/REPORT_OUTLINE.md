# Project report outline (follow college rules)

1. Title page — project title, student name, roll number, program/department, mentor name.
2. Abstract — 150–200 words.
3. Problem statement and domain context.
4. Objectives and research questions.
5. Dataset description and data dictionary (source, rows, columns, types, units, data quality).
6. Tech stack and libraries.
7. Methodology and Data Science pipeline (cleaning, EDA, statistical tests, feature engineering, model rationale, validation).
8. Results, visualizations and comparative analysis (tables, charts, metrics, confusion matrix, error analysis, application screenshots).
9. Conclusion, limitations and future scope.
10. References.

Formatting: Times New Roman or Arial; body 12 pt; headings 14–16 pt bold; 1.5 line spacing; justified paragraphs; numbered and captioned figures/tables. Submit one compiled PDF in `docs/` and on the official portal.

Do not invent results. Fill this report only after running the code and interpreting your actual outputs. Mentor name must be confirmed from your course.
